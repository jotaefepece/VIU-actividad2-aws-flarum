# Actividad 2 - Despliegue Flarum en AWS

## Descripción

Este repositorio contiene el desarrollo de la Actividad 2 de la asignatura de Computación en la Nube.

El objetivo principal es desplegar la aplicación web Flarum utilizando servicios de AWS, aplicando tanto despliegue manual como automatizado.

## Objetivos

* Crear una base de datos en AWS RDS
* Desplegar Flarum en Elastic Beanstalk
* Automatizar despliegue con CI/CD
* Definir infraestructura como código con Terraform
